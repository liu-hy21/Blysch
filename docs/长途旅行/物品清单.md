# 冲绳出行物品清单（按收纳分类）

衣服用压缩袋，湿装备用防水盒，其余用软包。硬盒只留给潜水件和怕压的数码。

装箱顺序（从底到上）：日常衣物 + 鞋袋 → 潜水盒、数码包、洗护包 → 贴身衣物、纸品、药品。证件现金包随身，不托运。

---

## 1. 潜水装备盒（硬防水盒 / 密封盒）

湿、盐、防雾剂，不和衣服、数码混装。回酒店先冲淡水再放回。

- [x] 黑色潜水帽
- [x] 白色潜水镜
- [x] 2 个白色咬嘴
- [x] 防雾剂
- [x] 黑色潜水袜套
- [x] 一盒耳塞鼻甲
- [ ] 泳衣
- [ ] 手机防水挂袋

## 2. 鞋袋（软袋即可，不必硬盒）

- [x] 洞洞鞋（可穿去机场，箱里只留沙滩鞋）
- [x] 黑色沙滩鞋

## 3. 数码包（带隔层软包，防压）

自拍杆细长，可沿箱壁竖放。手机走时再放，机身一般不装箱。

- [x] Action5（防水套、1 戴、1 包）
- [x] 手表线、Type-C 线
- [x] 自拍杆
- [x] 转换头、充电头
- [x] 有线耳机
- [x] 3C 充电宝
- [ ] iPad
- [ ] 两个手机

## 4. 证件现金包（薄拉链包，贴身，不进托运）

复印件、行程单与现金分开夹，丢了好补。

- [x] 钱包（身份证、Visa）
- [x] 护照
- [ ] 护照复印件
- [ ] 日元 25 万、500 人民币、硬币现金收纳袋
- [ ] 流量卡
- [ ] 打印行程单
- [ ] eVISA
- [ ] 提前 72 小时填 QR 码并截图
- [ ] 境外保险



## 5. 洗护液体包（密封洗漱包，防漏）

液体再套一层密封袋。登机若只带背包，防晒可单独拿出过安检。

- [ ] 防晒霜
- [ ] 花露水
- [ ] 剃须刀
- [ ] 洗脸洗澡帕子（湿的话单独密封袋）



## 6. 药品小盒（小号透明盒，放最上层或随身）

坐船那天晕船药要拿得出。

- [ ] 创口贴
- [ ] 晕船药
- [ ] 感冒药



## 7. 贴身衣物压缩袋（中小号）

酒店换洗不用翻整箱。

- [ ] 内裤、袜子
- [ ] 睡衣睡裤
- [ ] 眼罩



## 8. 日常衣物压缩袋（最大那只）

空顶帽垫最上面防压。伞可夹在这袋和箱壁之间。

- [ ] 衣服裤子
- [ ] 空顶帽
- [ ] 阿维塔伞



## 9. 纸品杂物扁包

酒店一般有纸巾，湿巾留 1 包随身即可。水杯空杯，放侧袋或箱角。

- [x] 垃圾袋
- [x] 口罩
- [ ] 湿巾 2 包、纸 10 包
- [ ] 水杯
