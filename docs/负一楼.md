# 负一楼

本文记**已经落地的室内负一楼**:娱乐层。户型依据 `docs/ui/california-mansion-floor-plan.html` 的 B1 平面;整屋风格见 `docs/乐园建筑美术设计.md`,一楼见 `docs/一楼.md`,二楼见 `docs/二楼.md`。

入口:`/me/park`,进屋后点「下」。`HouseScenery({ story: 0 })` → `buildBasementStory()`。

平面与楼上对齐:楼梯同在北墙核心筒 `32,24`,壳体仍是 `HouseShell`(南墙封死,无门洞)。气质换成地下酒廊:深木、暗砖红丝绒、绿台呢、暖金灯,南墙一条采光井把日光引进来。

未写进本文的装饰默认不画。

---

## 1. 设计风格

同一座住宅的**地下层**。材料跟楼上拉开层次但同一色相家族:天花深棕、墙是暖灰褐、地是深木条,点缀赤陶丝绒(影音椅)、绿呢(台球、棋牌)、黑钢(器械)、暖金(吧台踢脚、酒瓶)。

一句话:一楼是晒过的厨厅,二楼是冷光套房,负一楼是关灯喝酒看电影的地方。

### 定下来的形状

- 3/4 俯视,`SceneObject` + `Atom`,8px 原子,与楼上网格一致。
- **开放式娱乐层,无内隔墙。** 分区靠家具成团:西北酒吧、西墙酒窖、中央台球、东北影音、南侧健身与休息区。
- 南墙没有门,只有采光井高窗带 + 地上一片日光。
- 室内没有投影。灯是不透明暖黄块。

### 明确不画

- 出门热区;负一楼没有南门。
- 霓虹灯、LED 灯带、赛博蓝光。
- 点楼梯下楼。楼梯只作布景。

## 5. 楼层按钮

三层后按钮规则(`dream-client.tsx`,`story: 0 | 1 | 2`):

- 负一楼:上键金底可点(回一楼);下键浅色不可点。
- 一楼:上、下均可点。
- 二楼:上键浅色不可点;下键可点。
- 出门仍须先回一楼再点门;出到院子后 `story` 重置为 1。

## 6. 验收

缩到 480×640 仍须立刻读出:**幕布 + 台球桌 + 吧台**。不能读成车库或仓库。

1. 地是深木条,墙是暖灰褐,天花深棕;没有霓虹和蓝光。
2. 没有南门;采光井是南墙上一条亮玻璃 + 地上一片日光。
3. 下键在负一楼浅色不可点;上键金底回一楼。
4. 宠物不出现在负一楼。
5. 材质交界没有黑网格;器械、袋口用材料深色。
