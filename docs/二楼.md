# 二楼

本文只记**已经落地的室内二楼**：西浴、东卧。产品规则仍以 `docs/乐园系统设计方案.md` 为准。整屋与室外见 `docs/乐园建筑美术设计.md`。一楼见 `docs/一楼.md`。

入口：`/me/park`，进屋后点「上」。`HouseScenery({ story: 2 })` → `UpperStory`。

平面仍是西浴东卧，气质换成浅色开间套房：蜜橡木地板、奶油墙、胡桃家具、灰布软装、暖黄点灯。不是一楼的 Saltillo + 黑钢灶，也不是真等轴立体图。

未写进本文的装饰默认不画。

---

## 1. 设计风格

同一座洛杉矶西区西班牙复兴住宅的**楼上**。结构跟一楼对齐（楼梯、南墙封死），材料换成主卧套房：亮、浅、少赤陶。

一句话：一楼是晒过的厨厅；二楼是同一座屋里、光线更冷的卧室和浴室。

### 定下来的形状

- 3/4 俯视，`Cell` / `Bits`，8px 原子。禁止 `clip-path`、圆角、半透明影。
- **仍西浴东卧。** 地面连成一块，不立柱。
- 南墙封死。出门须先下到一楼再点门。
- 楼梯同一位置，只作布景。
- 室内没有投影。灯是不透明暖黄块。

### 明确不画

- 好莱坞天际线、窗里真泳池透视。
- 一楼那套赤陶地砖、灶、吊锅、壁龛烛。
- 出门热区；二楼没有南门。
- 点楼梯上楼。

## 2. 装修风格

左右不对称：浴缸和胡桃台在左；落地窗、灰沙发、床在右。眼睛路径：东窗 → 床。

### 2.1 平面

```
列  0–22       浴室（西）
列  23–32      北墙胡桃楣，地面连成一块
列  33–59      卧室（东）；楼梯 `33,58`
行  0–5        浅天花 + 细胡桃梁
行  6–21       北墙：浴窗、落地卧窗
行  22–69      蜜橡木地板
行  70–79      南墙封死
```

### 2.2 材料怎么读

| 部位 | 读成什么 | 不要读成 |
|------|----------|----------|
| 墙 | 奶油平涂，比一楼灰泥更亮 | 一楼那面晒过的灰泥 |
| 地 | 横向蜜橡木条 | Saltillo、黑格、白大理石 |
| 天花 | 浅米 + 细胡桃梁 | 一楼深木天花 |
| 浴缸 | 奶油硬边池 + 青水 | 赤陶槽 |
| 台盆 | 胡桃台 + 白盆 | 黑钢灶台 |
| 床 | 胡桃框 + 灰被 + 浅枕 | 一楼米垫沙发那套 |
| 沙发 | 灰布，靠东窗 | 深木框米垫客厅沙发 |
| 灯 | 暖黄点 + 一小条洒光 | 半透明光晕 |

### 2.3 浴室（西）

北窗冷色分格玻璃。窗左一面镜。窗下胡桃台、白盆。浴缸在地中央偏北，奶油池壁。灰米浴巾挂在东墙边。盆边一株绿植。宠物站在浴缸南、靠南墙那一带。

### 2.4 卧室（东）

落地窗比一楼厅窗更大，冷色 3×3 分格。窗下灰沙发 + 小胡桃几 + 灰椅 + 落地灯。床在毯上，头北，两侧白床头柜各一盏暖灯。头后一条矮奶油隔断。床尾胡桃凳。东南斗柜两点灯。挂毯槽仍在 `50,8`，布景不占那一格。

## 3. 实现技术

和一楼同一套网格与积木。`HouseShell({ southDoor: false, finish: "upper" })` 只换材料 class，不改几何。

二楼专用 class 前缀 `dream-la-up-*`，写在 `src/app/globals.css`。一楼 class 不要复用到二楼的墙和地。

等级家具仍走 `FurniturePiece`。卧室不渲染 `cow-bed`（布景床占主位）。

## 6. 验收

缩到 480×640 仍须立刻读出：**左边浴缸、右边灰床和落地窗**。地是木条，不是赤陶砖。

1. 一楼仍是灰泥 + Saltillo；上楼才换木地板。
2. 没有南门。上键浅、下键金。
3. 材质交界没有黑网格；灯是实色块。
4. 宠物只出现在当天抽到的浴室或卧室。
