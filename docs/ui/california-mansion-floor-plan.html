1F

一楼 · 社交层

LIVING / KITCHEN / DINING 建筑面积约 216 ㎡

布局要点:西厨东厅的开间式大空间,地面赤陶 Saltillo 通铺;厨房带中岛与北窗水槽; 楼梯与粉卫收进北墙中段的核心筒,不占采光面;客厅整面三扇推拉门朝南开向廊下露台—— 加州式的室内外连通。入户双开拱门对景穿过餐厅直抵北窗。

2F

二楼 · 寝居层

MASTER BEDROOM / BATH 建筑面积约 216 ㎡

布局要点:整层即一套主卧套房。西侧竖条依次是主卫(淋浴 + 双台盆 + 独立浴缸 + 马桶)、 衣帽间、洗衣房;东侧整开间是卧室,蜜橡木地板,床居中南向,床尾落地窗直通南向阳台。 楼梯间位置与一楼、负一楼上下对齐,结构柱网一致。

B1

负一楼 · 娱乐层

ENTERTAINMENT LEVEL 建筑面积约 216 ㎡

布局要点:出楼梯即是台球区,整个娱乐层环绕它展开——西北酒吧 + 恒温酒窖(玻璃门), 东侧台阶式地台影音室(隔声门),南侧健身房整面镜墙,并借南向采光井引入自然光; 影音室下方留一间休息区,看完电影直接转场棋牌。
