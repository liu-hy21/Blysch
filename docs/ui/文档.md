**1. 氨基葡萄糖（氨糖）——软骨营养支持**

- 常用的是[硫酸氨基葡萄糖]，成人一般一次0.25~0.5g，一日3次，口服
- 需要**连续服用2-3个月**才能评估效果，不是吃几天就见效的
- 对轻度损伤、软骨退变有一定辅助作用，但**效果因人而异**，不能替代正规治疗
- 注意：对本品过敏者禁用；**怀孕头3个月内应避免使用**；肝肾功能不全者慎用
- 市面上有药品级和保健品级之分，**药品级（OTC）的硫酸氨基葡萄糖**才有明确的治疗适应症，保健品只是辅助补充

常和氨糖搭配使用，作用是润滑关节、保护软骨。对轻度损伤或预防进展有一定辅助价值。
