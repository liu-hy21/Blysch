# 风格总览

参考图不是同一套皮肤。它们共享 **等距/斜俯视微缩**，但造型语言、材质、灯光、故事密度差很大。Blender 里一次只跟一族，不要把圆角马卡龙树贴到雨夜便利店上。

## 五族

| 族 | 参考图 | 一句话 | 适合做什么 |
|----|--------|--------|------------|
| A 卡通城市 | `refs/01` `02` `03` | 模块化、无贴图、游戏资产、高调棚拍 | 可拼街区、GLB 组件库 |
| B 软陶花园 | `refs/04` | 粘土玩具、极高倒角、粉彩、无叙事冲突 | 治愈微缩、花园装置 |
| C 低多边形和风 | `refs/05` | 硬边低面、冷背景热窗光、秋色点缀 | 单栋场景、氛围渲染 |
| D 都市切片 | `refs/06` `07` | 更写实的体块 + 强环境叙事 | 单点商店、雨夜/白天街角 |
| E 粉彩剖屋 | `refs/08` 成图 + 白模 | 切开的马卡龙公寓 | 乐园室内、家具、揭墙 |

A 是 **资产包**。B/C/D/E 是 **完成的一景**（E 带同一场景白模）。做城市拼装走 A；室内家具和剖开的一层屋走 E。

## 共用（五族都成立）

- 镜头几乎都是 **等距或 3/4 斜俯视**，建筑能同时看见屋顶和两面墙。
- 场景落在一块 **明确的底座** 上：城市用浅色地砖/沙色地面，花园用蛋糕式土层，和风用深蓝台座，便利店/咖啡用切边地台，剖屋用奶油+巧克力蛋糕台。
- 造型是 **积木感**：窗、门、树冠、车身都是可数的几何，不靠照片贴图讲故事。
- 颜色 **成套**：每族 5–8 个主色，同材质最多暗/中/亮三档。
- 细节给在 **轮廓和功能件** 上（遮阳棚、路灯、空调外机、招牌），不给在皮肤毛孔上。

## 和现有像素乐园的关系

像素屋是南加州灰泥 + 赤陶瓦 + 硬边矩形，禁止圆角。这批 Blender 参考 **全部大量使用圆角或斜面**，不能直接当乐园 CSS 的造型模板。

可借用的只有：

- **模块化拆件**（路、灯、树、店招分开做）
- **同材质三档色**
- **左右不对称的街区组合**
- **室内暖光 vs 室外冷光**（和风、便利店）

**3D 乐园室内** 跟 [10 粉彩剖屋](./10-粉彩剖屋.md)，不要拿 CSS 硬边去卡 Blender 家具。建筑外形若仍做南加州外壳，进门后切到 E。

工程侧（件数、实例、爆炸、合批）另见 [06 Atlas 积木实例化](./06-atlas积木实例化.md)，那是从 [P1 Atlas](https://lego-mclaren-p1-42172-atlas.vercel.app/) 抽出来的，不管这五族的外观。

## 推荐开工顺序

1. 乐园室内 / 宠物家具：直接锁 **E 粉彩剖屋**（有成图和白模）。
2. 需要室外街区组件时再开 **A 卡通城市**。
3. 需要「可爱静物院子」时用 **B**。
4. 需要「有故事的一栋夜景房子」时在 **C** 和 **D** 里选：秋日和室走 C，雨夜或日常店面走 D。
