# 04 雨夜便利店

参考：`refs/06-rainy-konbini.jpg`  
店名在图里是「雨宿り / AMAYadori · 24H」。做原创时换店名，保留 **站名牌式横招** 这个结构。

## 读图结论

雨夜里一座扁盒子便利店：大玻璃、内部货架被照亮，室外青瓷色墙、积水倒映「P」和斑马线。这是四族里 **最靠近当代插画/概念图** 的一套——仍然是积木，但有天气、有室内进深、有城市家具。

一句话：**青白色的避雨盒子，外面冷，里面暖。**

## 镜头与灯光

- 等距，视点略低，好让玻璃里的货架层可读。
- 环境是深蓝夜（`#0c1a28`），有雨丝（粒子或屏幕空间条）。
- 两套光：  
  - 室外：冷、弱、招牌灯箱自发光。  
  - 室内：暖白顶灯，透过玻璃 spill 到雨篷下的地砖。
- 地面要有 **模糊倒影**（积水平面，Roughness 很低）。路缘石、车位线、井盖在水里重复一次。
- 玻璃微暗、带一点青绿，不要全反射到看不见货。

## 造型语言

- 主体是扁平方盒，屋顶一圈深青压边，角部小圆即可，不要软陶圆。
- 正面几乎全是玻璃+深色框。横招是白底细字，像电车站名牌：左店名、中罗马字、右 24H。
- 左侧立式灯箱招 + 自动贩卖机，右侧员工门、空调外机、自行车。
- 货架：粉、绿、白的扁盒子重复，不建 SKU。雨伞桶是几根彩色圆柱。
- 人行是浅色地砖分缝；车行是深沥青 + 白色停车框。
- 电线、信号灯、禁止驶入牌把「这是街角」钉死，但都保持几何简洁。

## 场景零件清单

- 店壳体 + 玻璃 + 站名牌灯箱
- 室内：收银台、货架三进深、地板分缝
- 雨篷下：地垫、伞桶、小立牌
- 左：立招、贩卖机、路牌
- 右：员工门、空调、自行车、配电
- 前：人行砖、车位线、积水、井盖
- 上：电线杆、信号灯、雨丝、屋顶排风机

## 叙事要点（做像的最低条件）

1. 能从玻璃看见里面的货。  
2. 地上有水，水里有字或线。  
3. 店招是横长灯箱，不是竖着的霓虹草体。  
4. 室外青、室内暖，交界在雨篷下那一条。

## 明确不画

- 白天白棚、棒棒糖树、光滑球树。
- 写实人物撑伞特写（有也只做小比例剪影）。
- 复杂日文海报贴图堆满玻璃。
- 把屋顶做成和风瓦。
