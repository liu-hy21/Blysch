# 10 粉彩剖屋 Pastel Dollhouse

参考：`refs/08-pastel-dollhouse.jpg`（成图）、`refs/08-pastel-dollhouse-clay.jpg`（同一场景的 Blender 白模）

这是乐园 **室内 3D** 最近的一张完成稿：切开的一层公寓，浴室、卧室、洗衣间、客厅、厨房、阳台在同一块蛋糕台上。胡萝卜灯那件家具也按这个族做（倒角、粉彩、无贴图）。

## 读图结论

不是封闭房间，是 **娃娃屋剖盒**：去掉近处两面墙和天花板，正交等距一次看清所有功能区。墙很厚、角很圆，像积木砌的盒子。生活痕迹是摆出来的小件（纸箱、脏衣篮、蘑菇灯），不是贴图脏污。

白模图证明：先灰模摆满，父子物体用 Empty 串起来（虚线指向 3D 游标），相机锁等距，再上色。成图和白模房间划分一一对应，没有后期拼贴。

一句话：**切开的马卡龙公寓，家具是捏出来的。**

## 镜头与灯光

- 正交等距，俯角大约 35–40°，能看见地板拼缝和墙顶厚度。
- 白到浅灰棚（`#e8ecee` 一带）。没有窗射进的硬光斑。
- 主光从画面左上，软；补光翻半档，阴影浅、发暖。
- 灯具（蘑菇灯、台灯、浴室灯）可以弱 Emission，但场景主要靠棚光，不要便利店那种灯箱爆亮。
- 白模阶段就按这台相机工作，不要透视广角。

## 造型语言

- 倒角：**大于卡通城市，略小于软陶花园**。墙转角、台面、沙发扶手都是玩具圆，马桶盖、镜框也圆。禁止锋利踢脚线。
- 墙：厚板（视觉上约 12–18cm），顶面一条浅色边，像积木上表面。
- 地板：大块分色，不是木纹贴图。浴室薄荷砖、客厅浅桃、卧室更深一点桃，缝是色差不是凹槽贴图。
- 底座：两层蛋糕——上层奶油墙裙，下层巧克力台座，四角圆。花园那套台座语言搬进室内。
- 家具：方体 + 圆柱 + 扁球。床是圆角盒子加枕头球；沙发是三个圆角长方；圆茶几一块厚板四根短圆腿。
- 绿植：阔叶 3–5 片，陶盆倒角圆柱，不是 scraggly 写实枝。
- 画框：色块插画（花盆、日历格），不写真实品牌字。

剖法：保留左墙、后墙、一段右墙；近处（南 + 偏东）打开。阳台栏杆露出盒外。门洞是圆角方孔，能看见洗衣间进深。

## 房间划分（对着成图锁死）

从近到远、从左到右：

| 区 | 识别件（没有就不像） |
|----|----------------------|
| 浴室（左近） | 薄荷地、白马桶、圆镜、薄荷洗手柜、帘、花洒、地垫 |
| 卧室（左后） | 圆角床、竖条床头、蘑菇台灯、窗台空调箱、挂衣、床尾脏衣篮 |
| 洗衣间（后中，门洞里） | 洗衣机、圆凳、进深，不做成独立大厅 |
| 客厅（中） | 圆茶几、薄荷沙发、矮电视柜、地毯椭圆、遥控器色块 |
| 厨房（近中） | 双色小冰箱、薄荷地柜、壶、砧板、台灯 |
| 阳台（右） | 栏杆、盆栽、墙上海报 |

过道是客厅地一直铺到门洞，不要用墙把洗衣间封死。

## 家具与道具清单

按白模拆件，不要合成一个「房间 mesh」。

**浴室：** 花洒杆、帘、马桶、纸卷、地垫、圆镜、洗手盆+柜、瓶罐、毛巾。  
**卧室：** 床+床品、床头柜+蘑菇灯、窗、柜、空调、挂衣、搁板小盆栽、两幅画、脏衣篮、地板散物。  
**客厅：** 电视柜、电视、茶几+杯碟书本、沙发、抱枕、地毯、遥控器。  
**厨房：** 冰箱、地柜、台面锅壶、台灯、纸箱堆（未拆的生活感）。  
**阳台：** 栏杆柱、盆栽、画。  
**结构：** 地板分块、厚墙、门洞、蛋糕台座。

乐园现有兔/牛家具往这套语言靠：灯、垫、床、桌、凳都是圆角积木，不要像素块，也不要和风硬棱。

## 制作顺序（从白模图抄）

1. 蛋糕台座 + 厚墙剖盒 + 门洞。
2. 分色地板（浴室 / 居室）。
3. 大件：床、沙发、柜、厨柜、马桶——先占位。
4. 中件：茶几、洗手台、冰箱、洗衣机。
5. 小件：灯、画、植物、纸箱、杯。
6. Empty 分房间父级（`ROOM_BATH` `ROOM_BED` …），家具 parent 过去，方便整间移动和以后按层显隐。
7. 锁等距相机后再赋色板材质。白模看轮廓对不对；成图只加颜色和软阴影。

## 和乐园的关系

- **室内布景、解锁家具** 跟这一族，不要跟雨夜便利店或和风夜景。
- 剖盒等于方案里的「揭墙 / 无天花板」，Web 3D 默认可以藏南墙。
- 院子、南加州外壳仍可另做；进了门，语言切到本篇。
- 已做样件：`docs/blender/assets/rabbit-lamp.blend`（胡萝卜灯）、`docs/blender/assets/cow-can.blend`（牛奶罐）。色和倒角按本族。

## 明确不画

- 第四面墙、完整天花板（那就看不见布局）。
- PBR 木纹、瓷砖缝贴图、布料织纹。
- 夜景冷光、积水、霓虹。
- 硬边低面树、铁艺尖栏杆。
- 写实电线、螺丝、品牌 Logo。
- 把卡通城市的斑马线和消防车开进客厅。
