# 03 低多边形和风庭院

参考：`refs/05-lowpoly-japanese.jpg`

## 读图结论

夜色台座上的一栋两层和屋：青灰瓦、暖窗、左侧秋树、右侧针叶林墙、前庭枯山水、侧院温泉。树是 **看得见面的低多边形**，和卡通城市的光滑圆球树完全不是一种东西。

一句话：**积木神社旅馆，冷夜包一盏暖茶。**

## 镜头与灯光

- 等距，略侧，屋顶坡面要完整看见。
- 背景是纯色深靛紫（`#2a2438` 一带），不是白棚。
- 室外主光冷、弱；**室内窗纸是真正的发光体**（暖 `#f0c878`）。灯笼、庭灯同样发光。
- 温泉水面有高光环和蒸汽（体积或透明卡片）。
- 接触影比卡通城市实，台座边缘几乎溶进背景。

## 造型语言

- 树冠：Icosphere / 低面球，秋树橙红，针叶是圆锥叠锥。面要看得见，不要 subdivision 抹平。
- 屋顶：厚板叠成歇山/入母屋简化版，檐口一层深色边。瓦是色块，不雕每一陇。
- 墙：奶油色大面 + 深木框架。窗是规整障子格，格子本身就是装饰。
- 桥、鸟居、栏杆：深木细杆，截面方或圆都可以，但保持细。
- 枯山水：白砂平板 + 同心圆凹槽 + 三两块深灰石 + 一条石凳。
- 水面：左侧溪、右侧汤池，颜色偏青白，边缘用石块咬住。

建筑是不对称 L：主屋两层在左，平屋与汤在右。林墙只在后右，把地平封死。

## 场景零件清单

- 主屋两层 + 平屋
- 前庭砂纹 + 石组 + 石灯 + 凳
- 鸟居 + 小桥 + 溪
- 侧院木甲板 + 汤池 + 蒸汽 + 竹篱
- 秋树 4–6 棵（近处大、远处小）
- 背景圆锥林一排（高低错落，同一材质）
- 落叶碎点（砂上、甲板上的小橙片）

## 和卡通城市的关键差

| | 卡通城市 | 本族 |
|--|----------|------|
| 树 | 光滑圆球 | 低面棱球 / 圆锥 |
| 背景 | 白 | 深色虚空 |
| 窗 | 深色洞 | 发光格子 |
| 故事 | 白天街区功能 | 季节 + 仪式空间 |
| 倒角 | 玩具圆 | 几乎直角 |

## 明确不画

- 粉彩篱笆、棒棒糖花。
- 霓虹便利店招牌、积水倒影。
- 写实木纹贴图、每片瓦的法线。
- 白天高调棚拍（一改白底，和风力度会掉）。
