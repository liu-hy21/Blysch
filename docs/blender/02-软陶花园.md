# 02 软陶花园

参考：`refs/04-pastel-garden.jpg`

## 读图结论

一块方形草坪微缩，像生日蛋糕切面：上层绒草，侧面一层土色。中间凉亭，四周围栏，小径、喷泉、花架都是 **捏出来的圆棍子和圆片**。没有城市，没有硬阴影，没有文字。

一句话：**马卡龙花园，所有棱都融化。**

## 镜头与灯光

- 等距，略高于卡通城市，能看清亭顶和围栏内侧。
- 白棚（背景 `#e8e8ea`），顶光 + 大面积补光，阴影极浅、发青。
- 几乎没有镜面高光；塑料/粘土粗糙度偏高（0.4–0.6）。
- 可加极弱次表面散射，让亭柱和花瓣像糖。

## 造型语言

- Bevel 半径 **明显大于卡通城市**。树冠是光滑椭圆体，不是低面球。
- 围栏：白色扁条 + 圆头柱，像玩具木栅，不是铁艺尖刺。
- 树：一根焦糖色圆柱 + 一团薄荷绿球体。
- 花：棒棒糖（细杆 + 扁圆花头），粉/黄/紫/橙点缀，成小簇不单株铺满。
- 水池：白云朵外形的浅盆，水面是不透明粉蓝，三颗青珠当睡莲。
- 亭：六或八根圆木柱，顶是分瓣的冰淇淋色伞（浅木肋 + 薄荷瓦）。
- 底座：草地平面厚，侧面露一层巧克力土，底再垫更厚的台座。

草可以用短毛发或极浅的法线，但远看仍是平涂绿，不要真实草坪照片。

## 色板

| 用途 | 色 |
|------|----|
| 草 | `#8fbf6a` / `#a8d080` |
| 土台 | `#c4a07a` / `#a07850` |
| 白构件（篱、路、池沿） | `#f4f1ea` |
| 木 | `#d2a06a` |
| 亭顶 | `#d8efe8` |
| 水 | `#7eb8c4` |
| 花 | `#f2b6c8` `#f4d07a` `#c9b4e8` `#f4a07a` |
| 路灯头 | `#f0d9a0` |

饱和度整体低于卡通城市。如果一块红消防栓级别的纯色出现，风格就破了。

## 场景零件清单

- 围栏一周 + 前门小门
- 凉亭（桌、顶饰小球）
- 云朵喷泉
- 左右各一棵球树
- 花架/拱门 + 藤蔓小花
- 弯曲小径（白厚板）
- 杆灯、蘑菇、路牌
- 花簇若干，成团靠篱和亭脚

构图：亭在几何中心略后；喷泉在左前；入口在画面近沿正中。左右树不对称（一高一矮）。

## 明确不画

- 路网、汽车、混凝土牙。
- 硬边低面松树、夜景、窗格发光。
- 写实叶片、叶脉、泥土颗粒。
- 黑描边、像素块。
