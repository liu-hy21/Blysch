# 05 街角咖啡

参考：`refs/07-isometric-cafe.png`

## 读图结论

一座两层小方楼坐在浅砖台基上，墙是闷青灰，角落一圈路灯，门口有小板和盆栽，屋顶有空调和 Sathe 字样。尺度靠 **小人** 成立：灯柱比人高，橱窗比人略高。比便利店更日常、比卡通城市更闷、比软陶更「街」。

一句话：**阴天里的玩具咖啡楼，颜色都灰了一档。**

## 镜头与灯光

- 等距，俯角接近卡通城市。
- 环境阴天：天空灰蓝，没有硬影，没有窗内大爆发光。
- 灯是小球暖光，只点亮灯头附近，不照亮整条街。
- 背景可虚，焦点在建筑。

## 造型语言

- 平面接近正方形，二层略收，屋顶有厚檐圆角，像圆角矩形盒子。
- 墙面分缝少；窗是深洞+暖帘，一楼转角橱窗带绿褐条纹遮阳棚。
- 台基：牙砖一层 + 浅色大方砖地面。
- 路灯：细黑杆 + 弯臂 + 暖灯泡，四角或沿边阵列。
- 人：简模，大衣色块，点到为止。狗、看板、盆栽是前景锚。
- 屋顶设备（空调、通风、水箱）用浅灰扁盒子，让屋顶不空。

## 和 04 便利店的差

| | 便利店 | 咖啡楼 |
|--|--------|--------|
| 时间 | 雨夜 | 阴天 |
| 主色 | 青瓷高饱和 | 灰青低饱和 |
| 室内 | 必须看见货架 | 只透一点暖窗 |
| 地面 | 积水倒影 | 干砖 |
| 人物 | 无 | 有，用来定尺度 |
| 招牌 | 站名牌横招 | 小字 + 条纹棚 |

两张都可以当「一栋店」模板，但材质和天气不要混。

## 明确不画

- 十字路口车流、斑马线资产拼装。
- 软陶大倒角树冠。
- 夜雨和霓虹（那是 04）。
- 高饱和红消防栓当视觉中心。
