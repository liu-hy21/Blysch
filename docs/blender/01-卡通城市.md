# 01 卡通城市 Cartoon City

参考：`refs/01-cartoon-city-streets.jpg`、`refs/02-cartoon-city-buildings.jpg`、`refs/03-cartoon-city-asset-kit.jpg`

自称：Modular · Clean · Lightweight · Game Ready · Blender + GLB · Texture-free · 单件小于 1MB。

## 读图结论

这是一套 **等距城市积木**。建筑、路、车、树、家具同一套倒角和同一套日光。组合示例都是十字路口一块完整街区：底层商铺条纹遮阳棚、楼上开窗公寓、路牙种球树、路上两三辆扁圆形小车。

一句话：**玩具城市，不是沙盘仿真。** 体积厚、窗少而大、树是棒棒糖、路是灰布加白线。

## 镜头与灯光

- 正交等距，大约 35° 俯角。组合图能看见屋顶、南立面、西立面。
- 白到浅灰无缝背景（`#f4f6fb` 一带），物体下有很软的接触影。
- 主光从画面左上或右上，高光落在顶面和朝光立面；背光立面只降一档，不要死黑。
- 没有硬太阳斑、没有曝光拉爆的玻璃。

## 造型语言

- 所有外轮廓 **统一中等 Bevel**（看起来像 8–16mm 玩具倒角）。禁止锋利 90°，也禁止软陶那种融化圆。
- 路板块是带圆角的厚板；牙是米色厚边。
- 树：圆柱树干 + 一个或两个圆球树冠。樱花球粉、行道树叶绿、松树用锥体（资产包 03 才出现锥松）。
- 车：胶囊车身、大轮小窗、无后视镜、无雨刮。功能靠颜色和灯条识别（黄=出租，白红十字=救护）。
- 建筑：方盒子叠加。底层比楼层略高；阳台是薄板+栏杆；屋顶有水箱、晒衣、小棚，但都是大方块。
- 窗：深色洞或浅色玻璃板，格子少。学校用大钟楼和黄墙，医院用白墙大红十字，市政用圆顶+柱廊简化成积木。

## 资产清单（按三张表锁死）

做城市时按这个拆 collection，不要把一整条街做成一个物体。

### 路（Core 02）

1. 直道 2. 90° 弯道 3. T 字 4. 十字（斑马线） 5. 尽头 6. 人行/广场（树池+路桩）

尺寸要对齐：**一块路 = 一个网格单元**。弯道内侧牙是连续圆角，不是折线。

### 交通 / 边界 / 家具 / 停车

- 路灯（弯臂）、信号灯、路牌组（限速/P/转向）、公交候车亭

- 长椅、分类垃圾桶、花坛、消防栓
- 车位、充电桩、绿篱隔离带、道闸

## 组合规则

- 十字路口：四角建筑不要同高、同色。一角矮商铺、对角高公寓。
- 树种在路牙和建筑之间的窄绿带，不种在车行道上。
- 车少：一个路口 3–5 辆就够，方向不一致。
- 底层商业用 **暖色条纹棚** 把人行尺度钉住；楼上用更素的墙。
- 远景可复制同一栋改色，不要新开五种屋顶。

## 明确不画

- 真实沥青裂纹、油污、落叶堆。
- PBR 砖缝贴图、人物漫游、交通流量仿真。
- 透视相机造成的近大远小（资产表是正交的）。
- 把和风瓦顶、雨面积水、软陶篱笆混进来。
