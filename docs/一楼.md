# 一楼

本文只记**已经落地的室内一楼**：西厨、东厅、南门。产品规则仍以 `docs/乐园系统设计方案.md` 为准。整屋风格、室外、二楼概览见 `docs/乐园建筑美术设计.md`。二楼另见 `docs/二楼.md`。

入口：`/me/park`，进屋后默认这一层。`HouseScenery({ story: 1 })` → `LowerStory`。

未写进本文的装饰默认不画。

---

## 1. 设计风格

同一座洛杉矶西区西班牙复兴住宅的**里面**。材料跟院子一致：奶油灰泥、赤陶、深木、黑钢、铁。不是农舍厨房，不是开放式公寓白盒，不是酒店大堂。

一句话：情侣本子里「我们的一楼」，是南加州被晒过的开间——左边做饭，右边坐着，南墙正中那扇门对着院子。

### 定下来的形状

- 3/4 俯视，看得见北墙、天花木梁和地面。
- **开间，不是四宫格。** 西厨东厅地面连成一块。
- 南门只在一楼，和室外屋门同大：`8×10` 原子。
- 楼梯在厅西南角，只作布景。上楼靠页面上的「上」按钮，不点楼梯。
- 室内没有投影。高级感来自灰泥、Saltillo、灶的黑钢，不来自壁炉火焰。

### 明确不画

- 房间名牌、四宫格分割线、农舍壁炉、跳动火焰。
- 出门热区上的「出门」二字。
- 室内物件投影、半透明影、圆角、`clip-path`。
- 点楼梯上楼。楼梯不可点。

## 2. 装修风格

左右不对称。灶、吊锅、墙砖在左；沙发、毯、龛在右。眼睛路径：南门 → 北窗。

### 2.1 平面

```
列  0–22       厨房（西）
列  23–32      北墙木楣，地面连成一块
列  33–59      客厅（东，更大）；楼梯 `33,58`
行  0–5        天花 + 三条木梁
行  6–21       北墙：厨窗、厅窗、龛
行  22–69      Saltillo 地面
行  70–79      南墙；正中门 `26,70` 8×10
```

### 2.2 材料怎么读

| 部位 | 读成什么 | 不要读成 |
|------|----------|----------|
| 墙 | 奶油灰泥，左暗右亮 inset | 白乳胶、木板墙 |
| 地 | 16px 赤陶 Saltillo，缝是砖色 | 黑格地板、木地板 |
| 天花 | 深木底 + 三条梁 | 农舍原木堆、石膏线 |
| 灶 | 黑钢块 + 两点炭 | 不锈钢岛台 |
| 沙发 | 深木框 + 米垫 | 布艺转角、墨线卡座 |
| 龛 | 灰泥凹进去，里一盏烛 | 壁炉、电视墙 |
| 门 | 棕色门板 + 金把手，与室外同大 | 玻璃推拉、双开豪宅门 |

「有钱」= 灰泥墙、赤陶地、木梁、铁吊杆、龛里一烛。不是更多黑框，也不是镀金踢脚。

### 2.3 厨房（西）

窗在北墙，两侧木百叶。窗下两行错缝赤陶墙砖（和室外瓦同一套 class）。灶在窗左下，水槽贴窗。吊柜在窗左。铁杆上挂一块赤陶、一块金，当吊锅。台面是浅木压一条深木。

### 2.4 客厅（东）

北窗比厨窗大，窗下陶土花箱 + 三朵九重葛。东墙一个龛，烛在龛里。毯在沙发前，赤陶 / 米竖条，无描边。沙发朝南偏西。厅角一只陶盆，里面龙舌兰。楼梯贴厅西南、南墙里。

### 2.5 南门

门槛一块浅石，门板叠在南墙洞上，右下金把手，门槛上一小条暖黄洒光。热区盖住整扇门，透明，不再套一层按钮描边。

## 3. 实现技术

生产路径和室外同一套：**绝对定位的 CSS 矩形**，容器 `image-rendering: pixelated`。不做画布、瓦片地图、整张 PNG、Kenney、Pixi。

### 3.1 网格

```
原子 DREAM_ATOM = 8px
画布 60 列 × 80 行 = 480 × 640
定位：dreamPx(col, row, w, h) → left/top/width/height
```

定义在 `src/lib/dream-grid.ts`。一楼固定布景和厨 / 厅家具槽一律用格子，禁止百分比。

带轮廓的物体常用 **2×2 原子（16px）** 当最小可读块。1×1 只给把手、烛、花、炭。不要把一面墙拆成几十个描边方块。

### 3.2 两个积木

`LowerStory` / `HouseShell` 里只有这两种：

- `Cell`：一块矩形，格子坐标 + class。`pointer-events-none`。
- `Bits`：一串小块（厨窗下墙砖）。

重复物件抽成小组件：`Sofa`、`Range`。壳层 `HouseShell({ southDoor: true })` 两层共用；一楼传入开门的南墙。

### 3.3 描边规则

1. **整块材质**（天花、墙、地砖、门、灶）用一块 `Cell`，纹理走 `repeating-linear-gradient` / `box-shadow inset`。
2. **物体外轮廓**用材料深色 2px inset，不要 `var(--ink)` 把地砖切开。
3. **地砖缝**是赤陶深缝 `#8a3a32`，禁止黑线分格。
4. **毯、花、烛、洒光**无描边，靠色差叠。
5. 场景外壳 `.dream-scene` 仍是产品墨线框，那是 UI，不是装修。

### 3.4 CSS 禁令

- 禁止 `clip-path`、`border-radius`。
- 禁止模糊、半透明叠色。
- 室内禁止投影色块（室外那块房子影也不进室内）。

### 3.5 组件树

```
DreamClient
  文案行「点门口出门」+ FloorBtn 上 / 下
  ViewTransition
    HouseScene(story=1)
      HouseScenery → LowerStory
        HouseShell(southDoor)
        厨、厅加件
      FurniturePiece（area 为 kitchen | living）
      出门热区（仅 story===1）
      宠物（kitchen | living）
```

楼层状态在 `dream-client.tsx`：`story: 1 | 2`。一楼下键浅色不可点；上键金底可点。出到院子后 `story` 重置为 1。换层用 `startTransition` + `ViewTransition` 淡入淡出（`key={story}`），不是整页滑动。

## 7. 交互

| 操作 | 行为 |
|------|------|
| 点南门 | 出到院子，`story` 回到 1 |
| 点「上」 | `story = 2`，淡入二楼 |
| 点「下」 | 一楼禁用，浅色 `#efe6d4` / `#c4b49c` |
| 宠物 | 当天抽到 `kitchen` 或 `living` 才出现在这一层 |
| 双方无宠物 | 空屋可进、可出门 |

按钮只在室内出现，紧挨「点门口出门」右侧：先「上」后「下」，金底墨框，`h-11`。

## 9. 验收

缩到 480×640 仍须立刻读出：**南门 + 左边厨房右边客厅**。不能读成四宫格农舍。

1. 地是赤陶砖，墙是灰泥，灶是黑钢。没有壁炉。
2. 门热区可点出门，≥ 44px；热区上看不到「出门」二字。
3. 「点门口出门」右侧有上 / 下。下键浅、上键金。
4. 宠物只出现在当天抽到的厨房或客厅。
5. 材质交界没有黑网格；柜、砖缝用材料深色。
6. 楼梯在厅里看得见，点它没反应。
7. 放大后瓦缝、铁杆、门板仍是硬边像素。
