# 乐园建筑美术设计

像素风已定。本文记录**已经落地的室外和室内两层**。产品规则仍以 `docs/乐园系统设计方案.md` 为准：两人共用一座屋、默认室外、点门进出、家具按等级解锁。乐园页主路径是 WebGL（glTF），不是 CSS 像素屋。

本文取代旧稿里的农舍构图（泥地、木篱、河、粉三角屋顶、四宫格室内、壁炉），也取代上一版「15×20 逻辑格 + 屋檐烟囱」的未落地方案。`docs/乐园室外画面设计.md` 只保留那 16 位构图原则（一个焦点、有限色、硬边、成团）；场地和房子以本文为准。

未写进本文的装饰默认不画。

---

## 1. 这一座屋要像什么

洛杉矶西区独栋的西班牙复兴住宅：奶油灰泥、赤陶瓦、木百叶、铁门、棕榈、九重葛。不是农舍，不是玻璃盒豪宅，不是酒店大堂。

一句话：情侣本子里「我们的房子」，是南加州被晒过的前院立面。有钱感来自材料密、植物成团，不来自镀金。

### 定下来的形状

- 屋子是院子里的一件东西，不是整屏主角。墙约角色两倍高。
- **没有屋檐、没有烟囱。** 瓦顶和灰泥墙同宽，盖在墙上。
- 门是棕色方块 + 金把手 + 门上暖黄壁灯。进门热区盖住门，≥ 44px。
- 窗是黑框分格 + 两侧木百叶 + 窗下陶土花箱。
- 右侧院一条窄池，南沿两张躺椅；BBQ 在屋东南、步道和池之间。
- 南界是竖向木栅 + 正中铁门。左右绿篱。北侧一条天，两棵棕榈探进来。
- 地面是暖沙，草只在路左成圃。躺椅左侧不铺草。
- 室内是同一座屋的两层：一楼西厨东厅，二楼西浴东卧。南门只在一楼。

### 明确不画

- 好莱坞招牌、天际线、高速公路、车库门面。
- 横贯屏幕的河、整墙高水道、椭圆泳池。
- 农舍木篱、粉三角屋顶、`clip-path` 瓦。
- 每个物件都投影子。全场景只有**房子左侧**一块不透明沙色影。

## 2. 做出来之后，风格靠什么成立

高级感和精细度不是「格子再小一点、每块都描墨」。落地过程里证伪了几条：

| 看起来单薄 / 廉价的做法 | 改成 |
|-------------------------|------|
| 32px 大方块 | 8px 原子，瓦、草边、亮点用 1–2 原子 |
| 每个小块 `border: 2px` 墨线 | 同一材质是一整块；缝用材料深色，不是黑 |
| 整屏草坪 | 沙地当画布，草成不规则圃 |
| 屋顶两条红带 | 错缝小瓦，亮 / 中 / 暗三档赤陶 |
| 门是无细节的方块 | 壁灯、灯光洒在台阶、百叶和花箱 |
| 九重葛一条粉、棕榈一个 T | 成团的小色块叠叶 / 叠花 |
| 每个物件一块影子 | 只给房子投影，其余不投 |
| 屋檐探出、烟囱冒头 | 去掉。会把小屋读成农舍或贴纸 |
| 室内四宫格 + 壁炉火焰 | 开间厨厅；龛里一盏烛，不是农舍壁炉 |

「有钱」= 灰泥、赤陶、铁、木栅、植物、窄池。不是更多黑框，也不是半透明模糊影。

## 3. 技术栈（锁死）

生产路径：**Blender 资产 → glTF → Next.js 里 three / R3F**。乐园页允许 WebGL。不做瓦片地图、不接 Kenney、不上 Pixi。等级家具图鉴仍可用 2D `FurniturePiece`；场景布景不再用 CSS 原子块。

载体：`public/models/park/yard.glb`、`house-l1.glb`、`house-l2.glb`。进门 / 上下楼 / 出门仍是 HTML 按钮（热区 ≥ 44px）。负一楼尚未进 3D。

对照建模：`docs/blender/`。旧 60×80 CSS 网格只作历史对照，不再驱动乐园页绘制。

室外对照软陶花园 + 粉彩墙；室内对照粉彩剖屋。倒角、无贴图、棚拍光。不要把 CSS 像素屋规则搬回 WebGL。

## 6. 各材料怎么画

### 房子

瓦：先铺一块 `#8a3a32` 底，再铺 2×2 瓦，奇偶行错 1 原子。三档 class `dream-la-tile` / `-hi` / `-dk`，缝是 inset 赤陶，不是 border 墨。

墙：一块灰泥。`box-shadow: inset 10px 0 #e4d8c4, inset -8px 0 #fff8ec`，外沿 2px `#d4c4b0`。

门、窗、百叶、花箱叠在墙上。热区透明，不要再给门加一层黑框按钮样式。

### 地面

`.dream-yard`：`#d8c4a0` + 8px 间距的 1px `#c4a06a` 点，不是黑泥砖格。

草：多块小矩形拼锯齿边，里面 8px 一条深修剪纹。不要整屏横条。

路：浅石 8px 缝 `#b8b0a0`。池：亮青底 + 米色 inset 压顶，几点 `#f4fcfc`。

### 植物

棕榈冠用几块叠在一起的绿，无边。干有浅木条纹。九重葛三档玫瑰散点成团。龙舌兰竖条放射，贴池北。

### 南界与铁门

木栅是 90° 重复的宽木条，不是陶砖墙。铁门是竖条 + 一条横档，中间露出步道色。

### 躺椅与 BBQ

固定布景，不走家具解锁。躺椅：深木框 + 米垫 + 一头靠背。BBQ：铁身、赤陶表示炭、一侧木台。都不描产品墨线。

等级解锁家具（`FurniturePiece`）外形仍是旧墨框件，以后再迁。室外布景不靠它们；室内只摆 `area` 为厨房或客厅的件。

## 7. 动效

室外可以全静帧。若加：

- 池 / 泉：偶尔换 1×1 亮点位置，色不超出第 4 节。
- 九重葛、草、树：不要摆。
- `prefers-reduced-motion: reduce` 时全停。

场景切换继续用现有 ViewTransition 的淡入淡出，不是整页滑动。

## 8. 室内（三层）

同一座屋从里面看：3/4 斜俯视（星露谷式）。**一楼厨餐 + 客厅，二楼西条带（浴 / 衣帽 / 洗衣）+ 主卧，负一楼娱乐层。** 户型依据 `docs/ui/california-mansion-floor-plan.html`：粉卫与楼梯收进北墙中段的核心筒（楼梯 `32,24`，三层同一位置），不占采光面。楼层用页面提示旁的「上 / 下」切换，不点楼梯。一楼南门对着院子那扇门；二楼、负一楼没有出门洞。

**投影规则（不是正俯视，也不是等距）：** 镜头在南侧斜向下看，每个立体物件 = **顶面（亮）+ 南面（暗）**——南面挂在顶面下沿之外、z 低一层，南侧物件自然遮挡北侧（`object.ts` 的 `prism()`）。贴西墙的物件可见面是东面（如西墙台面、冰箱贴北墙则南面为正面）。北墙是竖直的背景墙，墙脚线交代落地；南墙是剖切矮墙，顶帽交代墙厚。地毯、地台等贴地物件保持平面，不画竖面。坐具的靠背一律朝南（对镜头），如一楼沙发、负一楼影院躺椅。

材料仍是灰泥、赤陶 Saltillo、深木、黑钢。没有农舍壁炉。

### 8.1 一楼平面

```
列  0–22       厨房（西北）+ 餐厅（西南）
列  23–40      核心筒：粉卫 c24–32、楼梯 c32–40（贴北墙）
列  41–59      客厅（东，更大）
行  0–5        天花 + 三条木梁
行  6–21       北墙：厨窗、楼梯高窗、厅窗
行  22–69      Saltillo 地面
行  70–79      南墙；正中门 `26,70` 8×10，与室外屋门同大
```

左右不对称：灶、中岛、餐桌在左，电视柜、沙发组在右。眼睛路径：南门 → 北窗。详细见 `docs/一楼.md`。

### 8.2 二楼平面

西条带三间（主卫 r22–48、衣帽间 r48–60、洗衣房 r60–70），条带东壁一堵隔墙开三个门洞；核心筒楼梯贴北墙；东侧整面主卧，南墙开阳台落地移门。材料换成蜜橡木地板、奶油墙、胡桃家具、灰软装。详细见 `docs/二楼.md`。

### 8.3 楼层按钮

只在室内出现，紧挨「点门口出门」右侧：先「上」后「下」，金底墨框，`min-h-11`。

- 负一楼：下键浅色不可点（`#efe6d4` / `#c4b49c`）；上键可点。
- 一楼：上、下均可点。
- 二楼：上键浅色不可点；下键可点。出门须先回到一楼再点门。
- 出到院子后回到一楼。

负一楼是娱乐层，详见 `docs/负一楼.md`；户型依据 `docs/ui/california-mansion-floor-plan.html`。

### 8.4 现网坐标（原子）

三层共用壳体（`HouseShell`）：天花 / 梁 `0,0` 60×6（梁 r1 / r3 / r5），北墙 `0,6` 60×16，西 / 东墙 `0,6` 与 `57,6` 3×66，地砖 / 地板 `3,22` 54×48，**核心筒楼梯 `32,24` 8×10 + 西壁扶手 `31,22` 1×12 + 顶部踏步沿 `32,24` 8×1（三层同一位置，只作布景）**。3/4 斜俯视的墙体交代：北墙脚踢脚线 `3,20` 54×2、西 / 东墙内沿 `2,6` / `57,6` 1×64、南墙顶帽 `0,70` 60×1。一楼南墙留门洞（`0,70` / `34,70` 各 26×10，顶帽在门洞处断开），二楼、负一楼南墙整条。

各层家具坐标：一楼见 `docs/一楼.md` 第 5 节，二楼见 `docs/二楼.md` 第 5 节，负一楼见 `docs/负一楼.md`。

厨 / 厅家具槽：桌 `8,32`、凳 `6,40`、罐 `19,14`、灯 `34,50`、窗台花 `46,16`、铃 `30,8`、谷仓灯 `36,40`。卧 / 浴：垫 `36,52`、毯挂 `50,8`、星灯 `8,8`、草垫 `34,56`、羊毛毯 `40,60`。

宠物当天抽 `yard | kitchen | living | bedroom | bathroom`（`DREAM_STATIONS`）。当前楼层看不到另一层的宠物。

## 10. 验收

### 室外

缩到 480×640 仍须立刻读出：**铁门、赤陶小瓦、灰泥小屋、两棵棕榈、路左草圃、右侧窄池和躺椅**。不能读成农场、粉屋子、河边小屋。

1. 瓦顶最饱和；沙、草、石都比它闷。池是侧边一条，不是主角。
2. 没有屋檐、烟囱、木篱圈地、河、`clip-path` 三角顶。
3. 从南铁门沿步道能走到门，中途绕开喷泉，**不路过泳池**。
4. 左右不对称。躺椅左侧是沙，不是草。
5. 除房子外没有投影。材质交界没有黑网格。
6. 进屋热区可点，≥ 44px。双方无宠物时空院可进。
7. 放大后瓦缝、铁条、池沿仍是硬边像素。

### 室内

缩到 480×640 仍须立刻读出：**一楼南门 + 左边厨房右边客厅**；上楼后是 **浴缸 + 木床**。不能读成四宫格农舍。
