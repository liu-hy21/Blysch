# 乐园建筑美术设计

像素风已定。本文记录**已经落地的室外和室内两层**。产品规则仍以 `docs/乐园系统设计方案.md` 为准：两人共用一座屋、默认室外、点门进出、家具按等级解锁、HTML + CSS 像素布景。

本文取代旧稿里的农舍构图（泥地、木篱、河、粉三角屋顶、四宫格室内、壁炉），也取代上一版「15×20 逻辑格 + 屋檐烟囱」的未落地方案。`docs/乐园室外画面设计.md` 只保留那 16 位构图原则（一个焦点、有限色、硬边、成团）；场地和房子以本文为准。

未写进本文的装饰默认不画。

## 1. 这一座屋要像什么

洛杉矶西区独栋的西班牙复兴住宅：奶油灰泥、赤陶瓦、木百叶、铁门、棕榈、九重葛。不是农舍，不是玻璃盒豪宅，不是酒店大堂。

一句话：情侣本子里「我们的房子」，是南加州被晒过的前院立面。有钱感来自材料密、植物成团，不来自镀金。

### 定下来的形状

- 屋子是院子里的一件东西，不是整屏主角。墙约角色两倍高。
- **没有屋檐、没有烟囱。** 瓦顶和灰泥墙同宽，盖在墙上。
- 门是棕色方块 + 金把手 + 门上暖黄壁灯。进门热区盖住门，≥ 44px。
- 窗是黑框分格 + 两侧木百叶 + 窗下陶土花箱。
- 右侧院一条窄池，南沿两张躺椅；BBQ 在屋东南、步道和池之间。
- 南界是竖向木栅 + 正中铁门。左右绿篱。北侧一条天，两棵棕榈探进来。
- 地面是暖沙，草只在路左成圃。躺椅左侧不铺草。
- 室内是同一座屋的两层：一楼西厨东厅，二楼西浴东卧。南门只在一楼。

### 明确不画

- 好莱坞招牌、天际线、高速公路、车库门面。
- 横贯屏幕的河、整墙高水道、椭圆泳池。
- 农舍木篱、粉三角屋顶、`clip-path` 瓦。
- 每个物件都投影子。全场景只有**房子左侧**一块不透明沙色影。

## 2. 做出来之后，风格靠什么成立

高级感和精细度不是「格子再小一点、每块都描墨」。落地过程里证伪了几条：

| 看起来单薄 / 廉价的做法 | 改成 |
|-------------------------|------|
| 32px 大方块 | 8px 原子，瓦、草边、亮点用 1–2 原子 |
| 每个小块 `border: 2px` 墨线 | 同一材质是一整块；缝用材料深色，不是黑 |
| 整屏草坪 | 沙地当画布，草成不规则圃 |
| 屋顶两条红带 | 错缝小瓦，亮 / 中 / 暗三档赤陶 |
| 门是无细节的方块 | 壁灯、灯光洒在台阶、百叶和花箱 |
| 九重葛一条粉、棕榈一个 T | 成团的小色块叠叶 / 叠花 |
| 每个物件一块影子 | 只给房子投影，其余不投 |
| 屋檐探出、烟囱冒头 | 去掉。会把小屋读成农舍或贴纸 |
| 室内四宫格 + 壁炉火焰 | 开间厨厅；龛里一盏烛，不是农舍壁炉 |

「有钱」= 灰泥、赤陶、铁、木栅、植物、窄池。不是更多黑框，也不是半透明模糊影。

## 3. 技术栈（锁死）

生产路径：**绝对定位的 CSS 矩形**，容器 `image-rendering: pixelated`。不做画布引擎、不做瓦片地图、不做整张 PNG 场景、不接 Kenney、不上 Pixi。仓库里若还有 `dream-pixi.tsx`，乐园页不采用。

### 网格

```
原子 DREAM_ATOM = 8px
画布 60 列 × 80 行 = 480 × 640
定位：dreamPx(col, row, w, h) → left/top/width/height
```

定义在 `src/lib/dream-grid.ts`。禁止用百分比摆建筑、室内外固定布景和厨/厅家具槽。卧室浴室家具仍用百分比，因为那些房间还没盖。

带墨线或完整轮廓的物体，常用 **2×2 原子（16px）** 当最小可读块。1×1 只给高光、把手、瓦缝错位。不要把一面墙拆成几十个描边方块。

### 两个积木

`YardScenery` / `HouseScenery` 里只有这两种：

- `Cell`：一块矩形，格子坐标 + class。
- `Bits`：一串小块（草边、九重葛、瓦、墙砖）。

重复物件抽成小组件：`Roof`、`Tree`、`Lounge`、`Bbq`、`Sofa`、`Range`。

### 描边规则

1. **整块材质**（墙、篱、路、池、南栅、门）用一块 `Cell`，纹理走 `repeating-linear-gradient` / `box-shadow inset`。
2. **物体外轮廓**可以用材料深色的 2px inset，不要 `var(--ink)` 把沙地、草、路切开。
3. **瓦与瓦之间**用赤陶深缝（`#8a3a32`），禁止黑线分格。
4. **植物、高光、躺椅垫**无描边，靠色差叠。
5. 场景外壳 `.dream-scene` 仍是产品墨线框，那是 UI，不是风景。

### CSS 禁令

- 禁止 `clip-path` 做屋顶、树、山。
- 禁止 `border-radius`（门、喷泉、泳池都是硬边矩形）。
- 禁止模糊、半透明叠色、渐变天空。天是平涂 `#9ec0d8`。
- 影子若做，必须是不透明色块（现用 `#b08a62`），且只有房子一块。

## 6. 各材料怎么画

### 房子

瓦：先铺一块 `#8a3a32` 底，再铺 2×2 瓦，奇偶行错 1 原子。三档 class `dream-la-tile` / `-hi` / `-dk`，缝是 inset 赤陶，不是 border 墨。

墙：一块灰泥。`box-shadow: inset 10px 0 #e4d8c4, inset -8px 0 #fff8ec`，外沿 2px `#d4c4b0`。

门、窗、百叶、花箱叠在墙上。热区透明，不要再给门加一层黑框按钮样式。

### 地面

`.dream-yard`：`#d8c4a0` + 8px 间距的 1px `#c4a06a` 点，不是黑泥砖格。

草：多块小矩形拼锯齿边，里面 8px 一条深修剪纹。不要整屏横条。

路：浅石 8px 缝 `#b8b0a0`。池：亮青底 + 米色 inset 压顶，几点 `#f4fcfc`。

### 植物

棕榈冠用几块叠在一起的绿，无边。干有浅木条纹。九重葛三档玫瑰散点成团。龙舌兰竖条放射，贴池北。

### 南界与铁门

木栅是 90° 重复的宽木条，不是陶砖墙。铁门是竖条 + 一条横档，中间露出步道色。

### 躺椅与 BBQ

固定布景，不走家具解锁。躺椅：深木框 + 米垫 + 一头靠背。BBQ：铁身、赤陶表示炭、一侧木台。都不描产品墨线。

等级解锁家具（`FurniturePiece`）外形仍是旧墨框件，以后再迁。室外布景不靠它们；室内只摆 `area` 为厨房或客厅的件。

## 7. 动效

室外可以全静帧。若加：

- 池 / 泉：偶尔换 1×1 亮点位置，色不超出第 4 节。
- 九重葛、草、树：不要摆。
- `prefers-reduced-motion: reduce` 时全停。

场景切换继续用现有 ViewTransition 的淡入淡出，不是整页滑动。

## 8. 室内（两层）

同一座屋从里面看：3/4 俯视。**一楼厨房 + 客厅，二楼浴室 + 卧室。** 楼层用页面提示旁的「上 / 下」切换，不点楼梯。一楼南门对着院子那扇门；二楼没有出门洞。

材料仍是灰泥、赤陶 Saltillo、深木、黑钢。没有农舍壁炉。

## 10. 验收

### 室外

缩到 480×640 仍须立刻读出：**铁门、赤陶小瓦、灰泥小屋、两棵棕榈、路左草圃、右侧窄池和躺椅**。不能读成农场、粉屋子、河边小屋。

1. 瓦顶最饱和；沙、草、石都比它闷。池是侧边一条，不是主角。
2. 没有屋檐、烟囱、木篱圈地、河、`clip-path` 三角顶。
3. 从南铁门沿步道能走到门，中途绕开喷泉，**不路过泳池**。
4. 左右不对称。躺椅左侧是沙，不是草。
5. 除房子外没有投影。材质交界没有黑网格。
6. 进屋热区可点，≥ 44px。双方无宠物时空院可进。
7. 放大后瓦缝、铁条、池沿仍是硬边像素。

### 室内

缩到 480×640 仍须立刻读出：**一楼南门 + 左边厨房右边客厅**；上楼后是 **浴缸 + 木床**。不能读成四宫格农舍。

1. 地是赤陶砖，墙是灰泥，灶是黑钢。没有壁炉。
2. 一楼门热区可点出门，≥ 44px；二楼没有门。
3. 「点门口出门」右侧有上 / 下。一楼下键浅、二楼上键浅。
4. 宠物出现在当天抽到的那一层房间。
5. 材质交界没有黑网格；柜、砖缝用材料深色。
